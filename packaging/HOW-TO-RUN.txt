EnzyDock 使用说明（免安装版）
================================================================

一、这是什么

    ★ 这是 Windows 版说明。如果你拿到的是 EnzyDock.app（Mac 版），
      请看同目录下的 HOW-TO-RUN-mac.txt，两边内容不一样。

    这是 EnzyDock 的免安装版本，程序自带 Python 和全部科学计算依赖。
    电脑上不需要安装 Python、RDKit、PySide6 或任何"运行库"，双击就能用。


二、怎么用

    0. 如果收到的是几个 .001 / .002 / .003 分卷（微信发不了大文件时
       会切成这样），先把它们和 merge-parts.bat 放在同一个空文件夹里，
       双击 merge-parts.bat，它会自动拼回一个完整的 zip，并核对指纹。
       看到 [ OK ] the archive is complete 就继续第 1 步。

    1. 把收到的整个 zip 解压到一个路径短、不含中文的目录，例如
           C:\EnzyDock
       解压后应该是这样（两个东西必须在一起，不能分开）：
           C:\EnzyDock\EnzyDock.exe
           C:\EnzyDock\_internal\      ← 约 536 个文件
    2. 双击 EnzyDock.exe。
    3. 首次启动约 3~10 秒，出现主窗口即成功。

    4. 跑完一次对接后，右下角的 Result 面板有两个页签：
           Poses         打分表（点一行就在 3D 里换一个构象）
           Interactions  该构象与蛋白的接触（氢键 / 盐桥 / 卤键 /
                         π 堆积 / 疏水接触），列出受体残基、配体原子和距离
       3D 视图上方还有一排开关，勾上 Contacts 就会在结构里画出这些接触
       （虚线颜色对应左下角的图例）；勾上 Surface 会显示蛋白表面。

    ★ 不要放在微信的接收目录里运行，也不要直接在 U 盘或压缩包里运行。
      微信目录会被自动清理，压缩包内是临时目录，都会导致启动失败或
      运行中途报错。


三、只收到了 EnzyDock.exe（约 13 MB）？那一定启动不了

    EnzyDock.exe 本身只是一个 13 MB 的启动器，它要用的 Python、RDKit、
    Qt 和 3D 组件全在旁边的 _internal 目录里（约 611 MB、536 个文件）。

    单独把 exe 拷走 / 只发 exe，就一定会报下面的错：
        Failed to load Python DLL ... LoadLibrary: 找不到指定的模块

    这不是缺运行库，也不用下载任何东西 —— 把整个目录一起发过来即可。
    最简单可靠的做法：发打包好的 zip（一个文件，解压出来就是完整目录），
    或者按上面的分卷方式发。切勿只挑 EnzyDock.exe 一个文件。


四、报错 "Failed to load Python DLL ... LoadLibrary: 找不到指定的模块"

    这句话的意思是：python312.dll 找到了，但它依赖的某个文件没找到。
    几乎都是复制 / 解压时文件没传全，而不是缺组件，也不用下载任何东西。

    请按顺序检查：

    1. 双击本目录下的 check-install.bat，它会核对关键文件和文件总数。
       如果显示 FAIL，就是没传全，让对方重新打包发一次即可。

    2. 用压缩软件重新解压，务必解压到 C:\EnzyDock 这类短路径，
       不要在压缩包里双击运行。

    3. 关掉杀毒软件（360 / 电脑管家 / Windows Defender）的实时防护后再
       解压，或把整个 C:\EnzyDock 目录加入白名单。杀毒软件会把 _internal
       里的 dll 当作可疑文件删除，症状与"文件没传全"完全一样。

    4. 如果 zip 文件"属性"页面底部有"解除锁定"复选框，勾选后再解压。

    5. 仍然报错时，可以把打包时生成的 SHA256 校验值拿来比对 zip：
       在命令行执行  certutil -hashfile 文件名.zip SHA256
       两边一致就说明传输无损，问题出在解压或杀毒软件上。


五、AutoDock Vina 已内置，无需另行安装

    这一版把对接引擎（AutoDock Vina 1.2.7）随程序一起提供，位置在：

        C:\EnzyDock\_internal\app\resources\bin\vina.exe

    解压后直接就能对接，不需要再下载或安装任何东西。
    （AutoDock Vina 采用 Apache 2.0 许可，允许随软件一起分发；
      版权归 The Scripps Research Institute，许可证正文在
      _internal\app\resources\licenses\ 目录下。）

    ★ 如果软件提示 "The AutoDock Vina that ships with EnzyDock could not
      be started"，通常是因为杀毒软件把上面那个 vina.exe 删掉了，
      或解压不完整。重新解压一次，并把 C:\EnzyDock 加入杀软白名单。

    ★ 想换成自己的引擎（QVina2、Smina 或更新版本的 Vina）也可以：
      打开菜单 File → Set Docking Engine ...，选中你的 exe 即可，
      它会优先于内置版本；再用 File → Use the Bundled Docking Engine
      可以切回内置的那一份。


六、3D 视图是空白的？

    远程桌面或虚拟机里没有显卡加速，请用兼容模式启动：

        EnzyDock.exe --web-compat

    也可以在桌面建一个快捷方式，在"目标"末尾加上空格和 --web-compat。


七、想知道环境是否正常

    在命令行里执行：

        EnzyDock.exe --selftest --report C:\EnzyDock-selftest.txt

    它会把每一项后端检查（RDKit、转换器、Vina 等）的结果写进那个 txt，
    把 txt 发回来即可定位问题。软件内的 Help 菜单里也有 Run Diagnostics。

    想连对接一起体检（会真跑一次对接，约 10~30 秒）：

        EnzyDock.exe --selftest --selftest-pdb 某个.pdb --selftest-dock ^
                     --report C:\EnzyDock-selftest.txt

    这份报告会多出两项：一次真实的 AutoDock Vina 对接，以及
    "Interaction analysis"（用刚才那个构象做 3D 相互作用分析）。
    两项都是 PASS，说明 3D 结果视图（蛋白 + 接触）在本机可用。
